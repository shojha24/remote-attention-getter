This project was made to help teachers refocus/engage with students that have attention issues without embarrassing the student or forcing the teacher to disrupt ongoing lessons to work with the student. I've learned so much about designing user-friendly electronics through this project already, and I can only hope to improve it even further!

https://docs.google.com/document/d/1pdbEuo4SmXSl6sLUVmqynjfnQwLkNhJojYhIHgMwM3E/edit?usp=sharing - This is some basic insight I had about the pros/cons of the project (price, functionality, future updates).

https://docs.google.com/document/d/1lhkbKkGVRqa9pIhL__DqxUnc8pqSw_GGtD7f7ZxA8ZQ/edit?usp=sharing - This contains rough instructions (to be updated with pictures) on how to assemble working teacher and student devices.

Note on Hardware_Resources:
You can order the PCBs online by uploading the "Teacher_Machine_Gerber.zip" onto a PCB manufacturing service (PCBway, JLCPCB)
You can 3D print the casings yourself (or order from an online printing service such as CraftCloud) using the .stl files.
